NVP Accounting — Privacy Policy

App: NVP Accounting  |  Bundle ID: com.pintoomali.nvpaccounting  |  Version: 1.0.0  |  Platforms: iOS, Android, Windows, macOS  |  Category: Business

Effective date: August 2026  |  Last updated: August 2026

✓ Data Not Collected

Overview

NVP Accounting does not collect, transmit, store remotely, or share any personal data. All data you enter — accounts, transactions, journal entries, GST records, and exports — stays exclusively on your device. There are no servers, no accounts, no cloud sync, and no analytics.

Data We Do Not Collect

  • No account registration, email address, or sign-in credentials
  • No names, phone numbers, or contact information
  • No financial figures, business data, or transaction records
  • No device identifiers, advertising IDs, or fingerprints
  • No usage analytics, crash reports, or telemetry
  • No location data
  • No third-party SDKs that collect data

Local Storage Only

All accounting records and exported files (PDF/CSV) are stored in your device's sandboxed Documents/ directory. Nothing is uploaded to any server at any time.

Platforms

NVP Accounting is available on iOS, Android, Windows, and macOS. On all platforms, all data is stored locally in an encrypted SQLite database (SQLCipher). There is no server, no cloud sync, and no cross-device data transfer initiated by the app. Users may manually transfer their database file between devices using the OS file system — the app does not do this automatically.

Network

NVP Accounting makes no background network requests and transmits no user data over the internet. The app has no server, no cloud sync, and no remote authentication — all data lives exclusively in an encrypted on-device database.

The only outbound connection the app may make is fetching web font files (e.g. Google Fonts) when a user generates a PDF from an imported HTML template that references those fonts. This fetch is user-initiated, one-directional, and contains no personal data — functionally identical to a browser loading a font for a web page the user opened.

File Access

The app reads and writes files only within its own sandboxed Documents/ directory. You may optionally import an existing database file via the system file picker — this file is copied locally into the app sandbox and the original is not modified or transmitted. Exported PDF and CSV files are saved to Documents/Exports/ (mobile) or a user-selected folder (desktop) and can be shared at your discretion.

App Password / Authentication

The app uses a locally-stored password to encrypt the on-device SQLite database (SQLCipher). This password never leaves your device. It is not stored on any server and cannot be recovered by us. ITSAppUsesNonExemptEncryption is set to false — no Export Compliance (ERN) is required.

System APIs Accessed (Required Reasons)

The following iOS system APIs are used solely for core app functionality and are declared in the app's PrivacyInfo.xcprivacy manifest:

API Purpose Reason Code
File Timestamps Display file modification dates in the UI C617.1, 3B52.1
Disk Space Check available storage before writing exports E174.1
UserDefaults Store app preferences locally on-device CA92.1

Third-Party Services

NVP Accounting does not integrate any third-party analytics, advertising, crash reporting, or data collection services. No data is shared with any third party.

Children's Privacy

This app is not directed at children under 13 and does not knowingly collect any information from children.

Changes to This Policy

If privacy practices change, this page will be updated with a new effective date. Continued use of the app after changes constitutes acceptance of the updated policy.
