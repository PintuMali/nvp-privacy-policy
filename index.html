NVP Accounting — Privacy Policy

Effective date: August 2026  |  Last updated: August 2026

✓ Data Not Collected

Overview

NVP Accounting does not collect, transmit, store remotely, or share any personal data. All data you enter — accounts, transactions, journal entries, GST records, and exports — stays exclusively on your device. There are no servers, no user accounts on our side, no cloud sync, and no analytics.

Data We Do Not Collect

  • No account registration, email address, or sign-in credentials sent to us
  • No names, phone numbers, or contact information
  • No financial figures, business data, or transaction records
  • No device identifiers, advertising IDs, or fingerprints
  • No usage analytics, crash reports, or telemetry
  • No location data
  • No third-party SDKs that collect data

Local Storage Only

All accounting records and exported files (PDF/CSV) are stored in your device's private, sandboxed app storage — on iOS in the app's Documents/ directory, on Android in the app's private data directory, and on desktop in the app's own data folder. Nothing is uploaded to any server at any time.

Platforms

NVP Accounting is available on iOS, Android, Windows, and macOS. On all platforms, all data is stored locally in an encrypted SQLite database (SQLCipher, AES-256). There is no server, no cloud sync, and no cross-device data transfer initiated by the app. Users may manually transfer their database file between devices using the OS file system — the app does not do this automatically.

Network

NVP Accounting makes no background network requests and transmits no user data over the internet. The app has no server, no cloud sync, and no remote authentication — all data lives exclusively in an encrypted on-device database.

The only outbound connection the app may make is fetching web font files (e.g. Google Fonts) when a user generates a PDF from an imported HTML template that references those fonts. This fetch is user-initiated, one-directional, and contains no personal data — functionally identical to a browser loading a font for a web page the user opened.

The app also displays a link to this Privacy Policy. Tapping it opens the page in your device's default web browser; no data is sent by the app.

File Access

The app reads and writes files only within its own sandboxed Documents/ directory. You may optionally import an existing database by selecting the folder containing it via the system file picker — the database and its key file are copied locally into the app sandbox for use. On logout, any changes made during the session are written back to the original file so your data stays current across sessions. No data is transmitted over the internet at any point. Exported PDF and CSV files are saved to Documents/Exports/ (mobile) or a user-selected folder (desktop) and can be shared at your discretion.

Camera & Photos (Optional)

In the Marketing / Advertisement module you may optionally attach an image to a product advertisement you create. When you tap "Add image", your operating system's standard photo picker (and, on some platforms, the camera) is presented so you can choose or capture a picture. Any image you select is embedded only in your local advertisement and its exported PDF — it stays on your device and is never uploaded to us or any third party. If you never attach an image, no photo or camera access occurs. You can decline the permission at any time; the rest of the app is unaffected.

App Password & Authentication

NVP Accounting protects your data with a password that you choose. The on-device database is encrypted at rest with SQLCipher (AES-256). Your password is never stored anywhere: it is run through Argon2id to derive a key that wraps a random database key using AES-256-GCM. Your password itself never leaves your device and is never transmitted to, or stored on, any server. We have no ability to read your password.

Password Recovery (Optional, User-Initiated)

Because we keep no copy of your password, we cannot silently reset it or access your data. For emergencies only, the app can generate an on-device recovery file (a copy of your database key sealed to our offline recovery key). This file remains on your device and is never transmitted automatically. If — and only if — you choose to email it to our support address to request an assisted reset, our offline tool can use it to help you regain access to your own data. We never receive this file otherwise, and we cannot decrypt your database without you voluntarily providing it. You may decline recovery entirely; in that case, if you lose your password your data cannot be recovered by anyone, including us.

Export Compliance (Encryption)

NVP Accounting uses only standard, published encryption algorithms (AES-256, Argon2id, X25519) solely to protect your own data at rest on your own device. It does not implement proprietary or non-standard cryptography. Accordingly, ITSAppUsesNonExemptEncryption is set to false.

System APIs Accessed (Required Reasons)

Third-Party Services

NVP Accounting does not integrate any third-party analytics, advertising, crash reporting, or data collection services. No data is shared with any third party. The "Advertisement" feature in the app is a tool for you to design marketing flyers for your own products; it does not display ads to you and collects no advertising identifiers.

Data Retention & Deletion

Because all data is stored only on your device, it exists only as long as you keep it. You can delete individual records from within the app at any time. To remove everything at once, uninstall the app (which removes its sandboxed storage) or delete the app's database file from your device's file system. Since we never collect or store your data, there is no remote copy to retain or delete — nothing persists with us after you remove it locally.

Children's Privacy

This app is not directed at children under 13 and does not knowingly collect any information from children.

Changes to This Policy
