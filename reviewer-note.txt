REVIEWER ACCESS — NVP Accounting (com.pintoomali.nvpaccounting)

FIRST-RUN FLOW:
1. Launch the app.
2. Tap "Get Started".
3. On "Create Application Password" enter any password of 6+ characters
   (e.g. "review123"), confirm it, tap "Create".
   This encrypts the local database on this device.
4. On the Login screen, use any of the 3 pre-seeded test accounts below.
   (Accounts are created automatically on first launch — no import needed.)

EXPORTS (PDF / CSV):
- Any module → Export button → Open / Download / Share
- Files saved to: Files app → NVP Accounting → Documents/Exports/

LOGOUT / SWITCH ACCOUNTS:
- Menu (top-left) → Logout → re-enter app password → Login with
  a different account email

"IMPORT EXISTING DATABASE" BUTTON:
- Visible on home screen (iOS only). This is for existing customers
  transferring their data from the desktop version. Reviewers do not
  need to use it — the 3 test accounts above are sufficient.

SIMULATOR NOTE:
- PDF Share sheet may appear empty on simulator — works on physical device.

NETWORK:
- No background network requests, no user data transmitted.
- Google Fonts may be fetched when generating a PDF from a user-imported
  HTML template — user-initiated only, no personal data sent.

ENCRYPTION:
- App password = local SQLCipher DB encryption only.
- ITSAppUsesNonExemptEncryption = false. No ERN required.
